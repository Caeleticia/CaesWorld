# Cae'sWorld · 每个人都能做卡牌

本轮只做 **动态 UI**：载入页面 + 主菜单。不含任何玩法内容。

---

## 运行

本项目是纯静态页面，但**不能直接双击 `index.html`**：`file://` 下浏览器会按 CORS 拦掉 `data/tips.txt` 的读取（界面仍然能用，会自动回落到内置的同一组字符库）。起一个静态服务器即可：

```bash
cd CaeAdventure
python3 -m http.server 8771 --bind 127.0.0.1
# 打开 http://127.0.0.1:8771/index.html
```

`index.html` 声明了 `<base href="./">`，部署在子目录下也能正确解析 `js/ css/ data/ assets/`。

## 色彩与风格

| 项 | 说明 |
| --- | --- |
| 主题色 | `#E5FFFF` —— 页面底色、侧栏渐变、选中态、进度条起点全部由它派生（浅一档 `#F7FFFF`，深一档 `#BDF3F3` / `#7FD8DD`） |
| 方格风格 | 整页方格纸：每 22px 一格细线，每 5 格一条重线；侧栏、便签、工具栏也自带方格 |
| 墨色 | 深青墨 `#17393C`，配合红笔 `#FF6B8B`（标题、手划下划线）与荧光笔黄 `#FFB020`（便签竖条、进度条末端） |
| 标题 | 手写体（细明 / 楷体回退链），`Cae's` 红、`World` 青，各自轻微旋转；副标题下是红笔手划的星点下划线 |
| 便签 | 「你知道吗」是钉在方格纸上的便纸条（胶带、黄竖条、轻微倾斜），换条时翻页动画 |

## 界面

### 载入页面
- 大标题 `Cae'sWorld` + 副标题「每个人都能做卡牌」
- 「你知道吗」：从 `data/tips.txt` 抽一条（**同一会话不连续重复**）
- 进度条：铅笔纸槽 + 荧光笔填充 + 流动斜纹 + 笔尖；进度只反映真实启动阶段，不空转
  - `正在启动界面` → `正在加载你知道吗字符库` → `正在加载图片资源` → `正在装配主菜单`
  - 右侧百分比，状态行带动态省略号；100% 后短暂停留再淡出进入主菜单

### 主菜单
- **左侧边栏**
  - 品牌：大标题（小号）+ 副标题
  - 你知道吗小纸条（可点右上角 `↻` 手动换一条，每 9 秒自动换）
  - 标签 + 弹出选项（手风琴：同时只展开一个，再点一次收起；`Esc` 收起）
    - 游玩：同屏 / 肉鸽 / 无尽 / 挑战
    - 测试：训练场
    - 设计：编辑器
    - 模组：模组管理
    - 设置：设置
- **右侧空白区域**
  - 每次进入随机载入一张图片：`castorice` 或 `hyacine`（拍立得样式，带胶带与名字标签；不连抽同一张）
  - 点击任意选项只弹出「界面占位，玩法待开发」提示，不进入任何玩法

### 响应式
- 宽屏：左侧边栏 300px + 右侧展示区
- 平板：边栏收窄到 250px
- 手机竖屏：上下布局，边栏变成顶部卡片，展示区在下

## 目录

```
index.html            入口（载入页 + 主菜单骨架）
css/theme.css         色板（#E5FFFF）、方格纸、手写标题、便签、通用动效
css/loading.css       载入页与进度条
css/menu.css          侧栏、标签弹出选项、右侧随机图片、手机布局
js/app.js             启动流程与界面编排（阶段调度、渲染侧栏、提示气泡）
js/loading.js         进度核心（阶段权重，纯逻辑）+ 图片预加载
js/tips.js            字符库读取 / 解析 / 不重复抽取（纯逻辑）
js/menus.js           菜单结构（纯数据）+ 手风琴逻辑
js/pictures.js        随机图片池与切换
js/icons.js           手绘风线性图标
data/tips.txt         你知道吗字符库（每行一条）
assets/pictures/      展示图片（castorice.png / hyacine.png）
tests/ui.test.js      纯逻辑单测（Node，无需浏览器）
```

## 测试

```bash
node tests/ui.test.js
```

覆盖：字符库解析（BOM / CRLF / 空行）、不连续重复抽取、随机源边界、读取失败回落兜底，菜单结构与手风琴，随机图片不连抽，进度条单调递增至 100%。

## 调试参数

| 参数 | 作用 |
| --- | --- |
| `?freeze=1` | 加载完成后停在载入页（只看载入页视觉） |
| `?freeze=menu` | 跳过载入页直接看主菜单 |
| `?tips=0` | 「你知道吗」不自动轮换 |

调试信息：`window.__cw`（字符库、来源、已加载图片、进度核心）。

## 修改字符库

直接编辑 `data/tips.txt`，每行一条，# 开头也会当成普通文本（不做注释）。文件读取失败时使用 `js/tips.js` 里的 `FALLBACK_TIPS`，增删条目时记得同步这两处。
